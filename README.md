## 🔧 If Something Does Not Work

Problems with a first download are usually simple to solve. Work through these in order:

**The page will not load.** Check your internet connection, then try a different browser. Sometimes a page simply needs a refresh.

**The download does not start.** Look for a link or button labelled with the version number or the word "download". If nothing happens when you click, right-click the link and choose **Save link as…**

**Windows blocks the file.** Click **More info**, then **Run anyway**. This appears because the file is new to Windows, not because anything is wrong.

**Nothing happens when you double-click.** Wait a few seconds — larger files take a moment to open. If it still does not respond, right-click the file and choose **Run as administrator**.

**You cannot find where it saved.** Press the Windows key, type the name of the file, and let Windows search for it. Alternatively open File Explorer and check the Downloads folder.

**Antivirus software complains.** Some security tools are cautious about any newly downloaded program. You can allow the file through your antivirus settings if you trust the source — and the source here is the official project page linked above.
